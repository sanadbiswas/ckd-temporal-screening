## Reproducibility finding

The published results reproduce exactly on Linux (Colab, 2 cores) with:
Python 3.13, numpy 2.4.6, pandas 2.2.3, scipy 1.16.3, scikit-learn 1.6.1,
xgboost 3.4.1 (Linux wheel, GCC 10.3.1), lightgbm 4.7.0,
imbalanced-learn 0.14.2, statsmodels 0.15.0, joblib 1.6.0,
threadpoolctl 3.7.0. On Windows, the same versions reproduce logistic
regression, random forest, histogram gradient boosting and LightGBM exactly,
but XGBoost's Windows build resolves a fold-1 hyperparameter near-tie
differently (scale_pos_weight 1.0 instead of 4.39), which changes model
selection. Official results should therefore be produced on Linux.

## Update of 19 November 2026 (before resubmission)

- `31_design_based_uncertainty.py` — the Rao–Wu bootstrap now uses the same
  seed as module 30 (`RANDOM_STATE + 3000`, previously `+ 3100`). Both
  modules therefore draw identical replicate weights, and the design-based
  intervals for weighted sensitivity, specificity and PPV in
  `R3c2_design_based_uncertainty.csv` (Supplementary Table S11) equal those
  in `R1c3_weighted_vs_unweighted_threshold.csv` (Table 6). Point estimates
  are unchanged; the other design-based intervals in that file shift
  slightly because they come from the new draws.
- `40_figure_data.py` (new) — writes the numbers behind every figure to
  `mlwa_results/figure_data/`, including the calibration-curve points
  (Figures 1 and 2) and the referral/case-finding curve (Figure 5), which
  were previously not saved.
- `41_make_figures.py` and `make_figures.py` (new) — draw Figures 1–6 and
  Supplementary Figure S1 into `mlwa_results/figures/` (EPS, PDF, PNG)
  without titles on the image, as the journal's guide for authors asks.
  `make_figures.py` can be run on its own to restyle a figure.
- `pipeline_runner.py` — two new stage methods, `export_figure_data()` and
  `make_figures()`.
- `ckd-runner-colab.ipynb` — two new cells that call these stages.

The original plotting code in modules 10, 15, 16, 24 and 26–36 is
unchanged and still writes its figures to `mlwa_results/` and
`mlwa_results/revision_round1/`.
